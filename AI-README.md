# AI Workspace Rules

This folder contains the Demigods & Derails rulebook, spreadsheets, CSV data, and RD-Gen5 webapps.

- Treat existing files and data as read-only unless the owner explicitly requests a change.
- Read the relevant rules and data before editing.
- Do not invent, remove, rename, or reinterpret content unless explicitly instructed.
- When a change is requested, update every matching source so the rulebook, XLSX, CSV, and apps stay synchronized.
- Preserve existing formatting and behavior unless the request requires otherwise.
- After editing, check for duplicate or missing data, validate syntax, and report exactly what changed.
- Never silently resolve a conflict. Flag it and ask before choosing between sources.

The XLSX/CSV ability data is the source of truth for shared abilities; `RD-Gen5/data.js` mirrors that data for the apps. The core rulebook is the authority for game rules unless the owner explicitly asks the app or another source to take precedence.
